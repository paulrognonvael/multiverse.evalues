routines.R gathers the function implementing the different e-variables discussed in the the paper

code.mcs.R gathers the code to analyze the teenager data (MCS dataset and MtF dataset).

plot.mcs.R gathers the code to produce the plots for the teenager data

Folder simulations_oneoutcome gathers the code and output of the simulations comparing the different e-variables discussed in the paper, when one has a single outcome

- simulations_oneoutcome/simulation.linear.R gathers the code for simulations in linear regression, the outputs are in /simulations/linreg

- simulations_oneoutcome/simulation.logistic.R gathers the code for simulations in logistic regression, the outputs are in /simulations/logreg

Folder simulations_multiverse gathers the code for the multiverse simulation study where one has multiple outcomes and treatments
