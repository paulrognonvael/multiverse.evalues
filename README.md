routines.R gathers the function implementing the different e-variables discussed in the the paper and the e-BH procedures.
code.mcs.R gathers the code to analyze the MCS dataset.
plot.mcs.R gathers the code to produce the plots relative to the MCS data analysis.
The folder /simulations gathers the code and output of the simulations comparing the different strategies to define e-variables discussed in the paper.
/simulations/simulation.linear.R gathers the code for simulations in linear regression, the outputs are in /simulations/linreg
/simulations/simulation.logistic.R gathers the code for simulations in logistic regression, the outputs are in /simulations/logreg
